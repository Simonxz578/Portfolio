# Immersive editorial / cinematic glass

The redesign keeps the existing Astro static site and GitHub Pages deployment. All 25 routes and the original factual data remain. There are no new runtime dependencies, remote fonts, analytics, model calls or third-party scripts.

## Design decisions

- Midnight `#071427`, ocean `#10253e`, mist `#b4cde3`, lavender `#c4b8ec` and paper `#f7f8f7`. Shared spacing, type, radii, focus, material and motion tokens live in `src/styles/global.css`; the old duplicated global cascade was replaced.
- Home uses real Cambridge river photography, a dark reading veil and the original portrait with its refined hair mask. No fabricated Cambridge imagery.
- Work presents Ninefold as a full-width layered world. The other four cases have system, research, academic-photography and community-photography compositions driven by the existing project records.
- Glass is restricted to navigation and controls. Research, résumé and detailed arguments use opaque reading surfaces.
- Existing system fonts provide a sans-serif reading/UI layer, with Georgia for restrained English display accents. No font downloads.
- Separate `scenes.css`, `cases.css` and `editorial.css` keep scene styling distinct from shared foundations. New reusable components: `HomeHero`, `WorkIntro`, `CaseStudyVisual`.
- The Ninefold walkthrough is explicitly illustrative. Native radio buttons choose the displayed diagnosis/scaffold/recheck; it does not call a model or claim to represent real students.

## Interaction and performance

- Transform-based button press and hover feedback; brief below-fold text arrival. Entire scene opacity is never faded, avoiding a pale first-paint flash.
- IntersectionObserver and requestAnimationFrame move only visible environment layers, by at most 16px. No scroll hijacking, perpetual particle system, WebGL or framework island.
- Reduced-motion CSS removes animation/transition and parallax; the script also stops depth updates. Main content remains visible without JavaScript; all walkthrough paths are readable in the unenhanced fallback.
- Mobile navigation manages focus, traps Tab while open, restores focus on Escape, closes outside/on navigation, makes background content inert and locks scrolling. Desktop breakpoint changes clear this state.
- Copy-email controls announce success/failure in the current language.
- Reused local compressed AVIF/WebP images, explicit dimensions and stable scene geometry. The universal background preload and hardcoded deployment-base CSS image paths were removed.
- Reference review: [Apple, Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/), [Apple, Get to know the new design system](https://developer.apple.com/videos/play/wwdc2025/356/), and the live Ninefold world. These were read-only references; the Ninefold application and repository were not modified.
